Untuk Siapa Sistem Ini?

Sistem ini melayani tiga peran utama dalam ekosistem bank sampah Kelurahan Sunggingan.

1

Petugas Bank Sampah RW

Input setoran nasabah dengan cepat saat sesi setor bulanan. Kelola daftar nasabah dan atur harga sampah per jenis.

2

Admin Desa / Perangkat Kelurahan

Pantau rekap seluruh RW, generate laporan bulanan untuk PKK Kabupaten, dan kelola pencairan saldo tabungan menjelang Lebaran.

3

Koordinator PKK

Akses data untuk pengisian Google Form Pilah Sampah PKK Kabupaten Kudus setiap tanggal 5.
